# dotmatch-site

Public pages for **Dot Match** by Bemty Studio, served with GitHub Pages
(Settings → Pages → Deploy from a branch → `main`, `/ (root)`).

| Page | Purpose |
|---|---|
| `index.html` | Landing page |
| `privacy.html` | Privacy policy (store listings and the game's Settings link here) |
| `support.html` | Support contact and FAQ |
| `style.css` | Shared style |

Static HTML only: no scripts, trackers or external fonts.
Later files planned here: `app-ads.txt` (AdMob) and `config/v1.json` (the game's remote config).

When the game starts using data in a new way, update `privacy.html` and its effective date first.
